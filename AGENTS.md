# Agent operating contract

After compaction, restart, or uncertainty, treat summaries as untrusted
locators. Reread `README.md`, `RIGHTS.md`, every upstream lock, the translation
registry, Git state, and the latest admitted release before mutation.

One writer owns one locale/source-ID range. Never modify formal Lean code,
another locale, an upstream fork, or generated release output. Use fully
qualified declaration IDs and exact source hashes. Preserve renames, failures,
rejected terminology, and superseded records append-only.
